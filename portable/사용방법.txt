주주명부 렌즈 - Windows 무설치판

1. ZIP 파일을 먼저 폴더에 모두 압축 해제하세요.
2. '주주명부렌즈.exe'를 더블클릭하세요. 기본 브라우저가 자동으로 열립니다.
3. 찾을 주주명을 입력하고 PDF를 선택해 분석하세요.
4. 사용 후 '주주명부렌즈_종료.exe'를 실행하면 이 폴더에서 켠 프로그램만 종료됩니다.

Windows 10/11 64비트, 최신 Edge 또는 Chrome이 필요합니다.
Node.js, Python, pnpm, OCR 프로그램을 별도로 설치할 필요가 없습니다.
실행 엔진과 한국어/영어 OCR 파일을 모두 동봉하여 인터넷 연결 없이 사용할 수 있습니다.
파일을 쓰고 실행할 수 있는 일반 폴더에 압축을 풀어 주세요. 관리자 권한은 필요하지 않습니다.
runtime, app, dist 폴더는 실행 파일과 항상 함께 두세요.

화면은 PC 내부 주소(127.0.0.1)에서 열립니다. 외부 서버를 운영할 필요가 없습니다.
PDF와 OCR 결과는 브라우저 안에서 처리하며 외부로 업로드하지 않습니다.
브라우저를 닫는 것만으로 백그라운드 실행 엔진이 종료되지는 않습니다.
다시 실행하면 이미 실행 중인 이 폴더의 화면을 열고, 다른 버전의 프로그램은 건드리지 않습니다.
포트는 자동 배정되므로 기존 버전의 포트와 충돌하지 않습니다.
폴더를 이동하거나 삭제하기 전에는 반드시 종료 프로그램을 먼저 실행하세요.
주소가 필요하면 실행 후 생성되는 'OPEN.url' 파일로 화면을 다시 열 수 있습니다.
임시 실행정보와 진단 로그는 data 폴더에 저장됩니다. PDF 원본은 저장하지 않습니다.

버전 정보: VERSION.json을 확인하세요. 무설치 패키지 버전과 분석 엔진 버전을 별도로 표시합니다.
OCR은 오인식 가능성이 있으므로 중요한 결과는 원본과 대조하세요.
실행이 안 되면 data/startup.log를 확인하세요. 회사 보안 정책에서 실행을 차단한 경우 담당자에게 문의하세요.
배포 파일은 전자서명되지 않았으므로 Windows에서 게시자 확인 경고가 표시될 수 있습니다.
이 파일은 Windows용이며 macOS/NAS용이 아닙니다.
