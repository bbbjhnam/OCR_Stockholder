# 주주명부 렌즈

여러 회사의 주주명부 PDF에서 지정한 주주의 주식 종류별 보유수량, 보유합계, 총발행주식수와 지분율을 추출하는 로컬 OCR 도구입니다.

## 주요 기능

- 텍스트 PDF와 스캔 PDF 동시 처리
- 띄어쓰기, 괄호, 하이픈 및 법인 표기 차이를 보정한 주주명 검색
- 보통주·우선주·상환전환우선주 등 종류별 수량을 별도 행으로 표시
- 보유수량 합계와 총발행주식수로 전체 지분율 계산
- 빠른 기본 분석 후 실패·저신뢰 문서만 정밀 재분석
- 결과를 CSV로 내보내기

PDF와 OCR 데이터는 외부 서버로 전송하지 않고 사용자의 브라우저 안에서 처리합니다.

OCR 언어파일과 실행 코어는 `public/_next/static/ocr/`에 포함됩니다. 서버가 제공하는 `.traineddata` 원본과 압축 전송용 `.traineddata.gz` 파일을 함께 유지해야 합니다.

## Windows 무설치판

배포 ZIP을 일반 폴더에 모두 압축 해제한 뒤 `주주명부렌즈.exe`를 실행합니다. Node.js·pnpm·Python을 따로 설치할 필요가 없으며 한국어/영어 OCR 파일도 포함됩니다. Windows 10/11 64비트와 Edge 또는 Chrome을 사용하세요.

기본 브라우저가 PC 내부 주소로 열립니다. 포트는 자동 배정하고 이 폴더에서 이미 실행 중이면 해당 화면을 재사용합니다. 종료할 때는 `주주명부렌즈_종료.exe`를 사용하세요. 다른 버전이나 다른 폴더의 프로세스는 종료하지 않습니다. 폴더를 옮기기 전에 먼저 종료하세요.

무설치판은 인터넷 연결 없이 동작하며 원본 PDF와 결과를 서버에 보내지 않습니다. `data/startup.log`에는 실행 진단정보만 남습니다. 실제 분석은 기존과 동일하게 브라우저에서 수행합니다.

### 무설치판 빌드 (개발자용)

Windows x64에서 의존성을 설치한 뒤 실행합니다.

```powershell
pnpm build:portable
# 동봉할 Node와 저장 폴더를 직접 지정할 수도 있습니다.
node scripts/build-portable.mjs --node C:\tools\node.exe --out D:\배포
```

Node 실행 파일, 프로덕션 빌드, 번들된 HTTP 실행기, 시작·종료 EXE, 라이선스와 SHA-256 목록을 출력합니다. 출력 폴더가 이미 있으면 덮어쓰지 않습니다. .NET Framework의 기본 C# 컴파일러는 빌드 시에만 사용하며 수신자는 컴파일러·개발도구가 필요하지 않습니다. Node 라이선스는 해당 버전의 공식 소스에서 받아 포함하며 `--node-license <파일>`로 로컬 사본을 지정할 수 있습니다. 생성된 폴더 전체를 ZIP으로 배포하세요. PDF·CSV·엑셀 등 사용자 문서는 포함하지 않습니다.

깨끗한 ZIP을 다른 경로에 압축 해제한 뒤 `pnpm test:portable "압축 해제한 패키지 폴더"`로 파일 해시, 외부 Node/PATH 비의존 실행, 동시 실행, 종료 인증, 폴더 격리, OCR 자산과 시작 잠금 복구를 검증할 수 있습니다. 이 검사는 브라우저를 열지 않고 시작·종료 EXE를 직접 사용합니다.

## 개발 요구사항

- Windows 10/11
- Node.js 22.13 이상

## 개발 실행

```powershell
pnpm install
pnpm dev
```

기본 개발 주소는 터미널에 표시됩니다.

## 테스트와 빌드

```powershell
pnpm test
```

이 명령은 파서·결과 가공·OCR 증거 선택 테스트를 실행한 뒤 프로덕션 빌드까지 검증합니다.

## 사용 방법

1. 찾을 주주명을 입력합니다.
2. 주주명부 PDF를 한 번에 선택합니다.
3. `1차 기본 분석`을 실행합니다.
4. 실패 또는 저신뢰 문서가 있으면 `2차 정밀 재분석`을 실행합니다.
5. 한 화면에서 모든 결과를 확인한 뒤 CSV로 내보냅니다.

## 주의사항

OCR 결과는 스캔 품질과 표 구조에 영향을 받습니다. `확인 필요`로 표시된 결과는 반드시 원본 주주명부와 대조하세요. 특히 문서에 인쇄된 지분율이 다른 주주 행에서 인식된 경우, 프로그램이 수량으로 다시 계산한 지분율과 다를 수 있습니다.
